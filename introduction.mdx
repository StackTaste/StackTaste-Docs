StackTaste remembers how you want software built. Teach it once. Cursor and your teammates stop repeating the same corrections.

Local Markdown in `.stacktaste/` is the working copy. Cloud is history, team sharing, and the dashboard.

## Live now

- Dashboard for preferences, policies, and lessons
- CLI login, init, sync, learn, review, check
- MCP tools and Cursor hooks
- Ranked context and generated `.cursor/rules`

## Later

Claude Code, Codex, Copilot, Windsurf, GitHub CI, packs, and billing. See [Coming soon](/coming-soon).

## How you use it

1. Create a project on [stacktaste.com](https://stacktaste.com).
2. Run `stacktaste login` then `stacktaste init` in a repo.
3. Cursor loads ranked taste on each session.
