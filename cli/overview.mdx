## Commands

| Command | Purpose |
| --- | --- |
| `login` / `logout` | Grant this machine, or revoke it |
| `init` | Link this repo and write agent files |
| `agents` | List or wire editors |
| `taste` / `list` | Catalog, or one item with history, PRs, and hits |
| `search` | Search local taste |
| `learn` | Capture a proposed item |
| `review` | List proposals, or accept / reject one |
| `pull` / `push` / `sync` | Cloud |
| `check` | Scan changed files for blocking policies |
| `status` / `doctor` | Health |
| `mcp` / `hook` | Stdio. Cursor starts these |

`export` and `import` are not implemented.

## Auth

See [Login](/cli/login). Override the API with `STACKTASTE_API_URL` (the RPC URL, including `/rpc`).
