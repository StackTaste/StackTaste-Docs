```bash
stacktaste help
```

| Command | Purpose |
| --- | --- |
| `login` | Browser grant, then init |
| `logout` | Drop token, revoke grant |
| `init` | Link this repo |
| `agents` | List or wire editors |
| `pull` / `push` / `sync` | Cloud |
| `status` / `doctor` | Health |
| `search` | Local search |
| `learn` / `review` / `check` | Capture, accept, scan |
| `mcp` / `hook` | Stdio. Quiet. Used by Cursor |

`export` and `import` are not implemented.

## Install

The package is `@stacktaste/cli` on npm. The binary is `stacktaste`.

<CodeGroup>

```bash npm
npm install -g @stacktaste/cli
```

```bash pnpm
pnpm add -g @stacktaste/cli
```

```bash yarn
yarn global add @stacktaste/cli
```

```bash bun
bun add -g @stacktaste/cli
```

</CodeGroup>

Or run without installing:

<CodeGroup>

```bash npm
npx @stacktaste/cli login
```

```bash pnpm
pnpm dlx @stacktaste/cli login
```

```bash yarn
yarn dlx @stacktaste/cli login
```

```bash bun
bunx @stacktaste/cli login
```

</CodeGroup>

## Auth

See [Login](/cli/login). Override the API with `STACKTASTE_API_URL` (RPC URL, including `/rpc`).
