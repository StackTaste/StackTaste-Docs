A StackTaste project is the unit of members, roles, and keys. There is no nested organization under a project.

## Members

`/app/settings/members`

Invite by email. Built-in roles: `owner`, `admin`, `member`. Custom roles pick from the same ACL.

## Roles

`/app/settings/roles`

Do not edit `owner`, `admin`, or `member`. Taste verbs: `read`, `write` (propose), `publish` (accept/reject), `delete` (proposed forks only).

## Project keys

`/app/keys`

Lists CLI grants and CI keys for this project. Prefix `st_`. Revoke from here.

CLI login mints a key for **one** project. Metadata includes detected editors and last pull time.
