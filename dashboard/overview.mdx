Projects live at `/{org}/{project}`. The organization shell is `/projects` for the project list, billing, and invoices.

## Overview

Project health: people, machines, live taste, awaiting review, month-to-date edits.

**Agents connected** lists editors that have a machine on this project. Cursor is the live editor.

## Taste list

One model, three routes:

| Route | Filter |
| --- | --- |
| `/{org}/{project}/preferences` | Preferences and conventions |
| `/{org}/{project}/policies` | Policies and exceptions |
| `/{org}/{project}/lessons` | Lessons |

Propose from the header. Open an item for body, confidence, history, suggestions, accept, reject, reinforce, or fork.

The same catalog is in the terminal: [`stacktaste taste`](/cli/taste).

## Review

| Action | Result |
| --- | --- |
| Accept | Status becomes `active`. Agents can inject it |
| Reject | Archived. Never reopens. Fork to try again |
| Reinforce | “Hit this again.” Confidence goes up |
| Suggest | A PR on live taste. Merge writes a version |

Same accept / reject: `stacktaste review accept|reject <id>`.
