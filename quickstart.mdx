---
title: Quickstart
description: Sign in, pick a plan, link a repo, and wire Cursor.
---

Cursor is the live agent. Other editors can be wired as stubs.

<Steps>
	<Step title="Create a project">
		Sign up at [stacktaste.com](https://stacktaste.com). Choose **Sip** or **Stack** for the organization, then create a project.
	</Step>
	<Step title="Grant this machine">
		In the repo:

		<CodeGroup>

		```bash npm
		npx stacktaste login
		```

		```bash pnpm
		pnpm dlx stacktaste login
		```

		```bash yarn
		yarn dlx stacktaste login
		```

		```bash bun
		bunx stacktaste login
		```

		</CodeGroup>

		A browser tab opens. Pick **one** project. The token is stored in the OS keychain, never in git.

		Press Ctrl+C after login if you want to init later.
	</Step>
	<Step title="Link the repo">
		<CodeGroup>

		```bash npm
		npx stacktaste init
		```

		```bash pnpm
		pnpm dlx stacktaste init
		```

		```bash yarn
		yarn dlx stacktaste init
		```

		```bash bun
		bunx stacktaste init
		```

		</CodeGroup>

		The wizard asks which project, where `.stacktaste/` should live, and which agent. Pick **Cursor**. It pulls team taste and writes MCP, hooks, and `.cursor/rules`.
	</Step>
	<Step title="Open Cursor">
		Start a chat in that repo. StackTaste attaches ranked taste at session start. Blocking policies show a **StackTaste Alert** and do not run.
	</Step>
</Steps>
